🧠 MemPro：代理記憶系統作為可進化程式

arXiv:2606.00619 · 2026-06-02 · AI Agent Memory
記憶管線 遺傳演算法 LLM Agent 自動優化 RAG 進化計算
🧠 一句話結論：MemPro 將 LLM Agent 的整個記憶管線（構建–檢索）變成一個可進化的程式——不僅僅是調整 prompt 或向量存儲，而是讓系統跨世代自動優化整個記憶架構。

🔧 機制拆解

問題

傳統 LLM Agent 記憶系統使用固定管線：從對話歷史構建記憶 → 需要時檢索。這個管線由工程師手動設計（何時寫、寫什麼、何時檢索、檢索多少），無法適應不同任務的特性。

MemPro 的解決方案

  1. 將管線表示為程式：整個記憶構建-檢索（Memory Construction-Retrieval, MCR）管線被編碼為結構化代碼，而非靜態 prompt 或 YAML 配置。這讓管線具備完整的表達能力——可以實現條件分支、迴圈、甚至遞歸的記憶策略。
  2. 通過遺傳演算法進化：每個「個體」是一個管線版本。族群中的個體經過交叉（組合不同策略）、突變（隨機修改參數或邏輯）、選擇（淘汰低分者），跨世代向更優解收斂。
  3. 更廣的搜索空間：不僅優化檢索參數（top-K、相似度閾值），MemPro 還進化：記憶寫入策略（何時寫、怎麼摘要壓縮）、記憶組織結構（分層 vs 平面 vs 圖形）、以及檢索後的後處理邏輯（去重、排序、融合）。

與現有方案的差異

方案優化對象局限性
傳統 RAG固定管線 + 手動調參無法適應任務變化
Memory-R1 (RL)學習 ADD/UPDATE/DELETE 策略僅優化操作，不改管線結構
DSPy優化 prompt 文本不改記憶架構
MemPro整個 MCR 管線程式全域結構 + 參數同步進化

🚀 落地應用

  1. 長期運行的 AI Agent：部署 MemPro，讓它在實際使用中根據用戶互動模式自動進化出最優記憶策略——不再需要工程師為每個場景手調管線。
  2. 自動化 RAG 系統：將整個 RAG 管線（分塊策略 → 嵌入選擇 → 檢索演算法 → 重排邏輯）作為進化單元，讓遺傳演算法找到最優組合。
  3. 節省大規模成本：最優管線減少 40% 不必要的 LLM 調用——對每日處理百萬次請求的生產系統，這是可觀的成本節約。
  4. 擴展方向：同樣的思路可應用於 Agent 的其他管線——規劃（planning）、工具選擇（tool selection）、自我反思（self-reflection），最終實現「全自動 Agent 架構搜索」。
📌 核心差異：MemPro 不是又一個記憶優化技巧——它是一個元框架。它把「設計記憶管線」這個原本需要人類專家數周反覆迭代的問題，變成了讓演算法在數小時內自動搜索的問題。這是從「工程師寫策略」到「工程師定義搜索空間」的範式轉移。
