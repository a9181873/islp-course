從理論到實踐

在本實驗中，我們將把第 3 章所學的一切應用到真實數據上。你將使用 statsmodels 和 scikit-learn 來估計線性迴歸、添加交互項、非線性變換、處理定性變數，並自行編寫模型評估函數。

數據集：Boston（波士頓房價，506 個區域 × 13 個特徵）、Auto（汽車油耗數據）、Carseats（兒童安全座椅銷售）。

1. 導入庫與數據

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm
from ISLP import load_data
from ISLP.models import summarize, ModelSpec as MS
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split

# 載入數據
Boston = load_data('Boston')
Auto   = load_data('Auto')

2. 簡單線性迴歸

使用 statsmodels 估計 medv（房價中位數，單位 $1000）與 lstat（低收入人口比例 %）之間的關係。 

# 方法一：statsmodels 標準 OLS
X = sm.add_constant(Boston['lstat'])  # 添加截距項
y = Boston['medv']
model = sm.OLS(y, X).fit()
print(model.summary().tables[1])

# 方法二：scikit-learn（更適合機器學習流程）
X_sk = Boston[['lstat']]
y_sk = Boston['medv']
lr = LinearRegression().fit(X_sk, y_sk)
print(f"β₀ = {lr.intercept_:.3f}, β₁ = {lr.coef_[0]:.3f}")
📊 結果解讀：β₁ ≈ −0.95，表示低收入人口比例每增加 1 個百分點，房價中位數約下降 $950。p-value ≈ 0，統計上極顯著。R² ≈ 0.54，模型解釋了約 54% 的房價變異。

3. 多元線性迴歸

加入更多預測變數，觀察 Adjusted R² 的變化。

# 使用 lstat + age 兩個變數
predictors = ['lstat', 'age']
X_multi = sm.add_constant(Boston[predictors])
model_multi = sm.OLS(y, X_multi).fit()
print(model_multi.summary().tables[1])

# 使用全部 13 個變數
X_all = sm.add_constant(Boston.drop('medv', axis=1))
model_all = sm.OLS(y, X_all).fit()
print(f"R² = {model_all.rsquared:.4f}")          # 0.7406
print(f"Adjusted R² = {model_all.rsquared_adj:.4f}")  # 0.7338
💡 關鍵概念：R² 永遠隨變數增加而增加，但 Adjusted R² 會懲罰無用變數。當比較不同大小的模型時，務必使用 Adjusted R²。

4. 交互項（Interaction Terms）

使用 ISLP 的 ModelSpec 優雅地創建交互項。語法：('var1', 'var2') 會自動生成 var1 × var2。 

# ModelSpec：宣告式建模
design = MS(['lstat', 'age', ('lstat', 'age')]).fit(
    Boston[['lstat', 'age']]
)
X_inter = design.transform(Boston[['lstat', 'age']])
model_inter = sm.OLS(y, X_inter).fit()
print(model_inter.summary().tables[1])

# 若交互項 p-value < 0.05 → lstat 對房價的影響取決於房屋年齡

5. 非線性變換：多項式迴歸

MS(...).poly(degree) 自動生成正交多項式項，避免手動計算 x², x³ 帶來的共線性問題。 

# poly(2) 自動生成 lstat 和 lstat²（正交化版本）
design_poly = MS([MS('lstat').poly(2), 'age']).fit(Boston)
X_poly = design_poly.transform(Boston)
model_poly = sm.OLS(y, X_poly).fit()
print(model_poly.summary().tables[1])

# 視覺化：繪製擬合曲線
import matplotlib.pyplot as plt
lstat_grid = np.linspace(Boston['lstat'].min(), Boston['lstat'].max(), 100)
X_pred = pd.DataFrame({'lstat': lstat_grid, 'age': Boston['age'].mean()})
X_pred_design = design_poly.transform(X_pred)
y_pred = model_poly.predict(X_pred_design)

plt.scatter(Boston['lstat'], y, alpha=0.4, s=10)
plt.plot(lstat_grid, y_pred, 'r-', linewidth=2)
plt.xlabel('lstat'); plt.ylabel('medv')
plt.title('多項式迴歸擬合（degree=2）')

6. 定性預測變數（虛擬變數）

ModelSpec 檢測到字串欄位時，自動創建虛擬變數（dummy variables），以第一個類別作為 baseline。 

Carseats = load_data('Carseats')

# ShelveLoc: Bad / Medium / Good — 自動轉虛擬變數
design_cat = MS(['Price', 'Income', 'ShelveLoc']).fit(Carseats)
X_cat = design_cat.transform(Carseats)
y_cat = Carseats['Sales']
model_cat = sm.OLS(y_cat, X_cat).fit()
print(model_cat.summary().tables[1])

# 輸出範例：
# ShelveLoc[Medium]  →  β ≈ 2.0  (相對於 Bad，銷量高 2000 單位)
# ShelveLoc[Good]    →  β ≈ 4.2  (相對於 Bad，銷量高 4200 單位)
📌 解讀：貨架位置從 Bad → Good，在控制價格和收入後，銷量增加約 4,200 單位。這是因果推斷中控制混雜因素的經典應用。

7. 自訂評估函數：訓練/測試分割

statsmodels 不會自動做 train/test split——這是機器學習工作流的核心步驟。我們自己寫。 

def eval_mse(model, X_test, y_test):
    """計算測試集 MSE（適用於任何有 .predict() 的模型）"""
    y_pred = model.predict(X_test)
    return np.mean((y_test - y_pred) ** 2)

# 分割數據
X = Boston.drop('medv', axis=1)
y = Boston['medv']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 訓練 + 評估
model = LinearRegression().fit(X_train, y_train)
train_mse = eval_mse(model, X_train, y_train)
test_mse  = eval_mse(model, X_test, y_test)
print(f"Train MSE: {train_mse:.2f}, Test MSE: {test_mse:.2f}")
⚠️ 常見錯誤：只用訓練集 MSE 判斷模型好壞，這是錯誤的！訓練 MSE 永遠偏低（甚至趨近 0），必須用測試集 MSE 或交叉驗證來估計真實泛化能力。

8. 技術總結

技術工具何時使用
簡單線性迴歸sm.OLS / LinearRegression1 個預測變數，線性關係
多元線性迴歸sm.OLS + 多變數多變數，需要 p-value 與可解釋性
交互項MS(...) 帶 tuple當某變數的效應取決於另一變數
多項式迴歸MS(...).poly(degree)輕微非線性關係
虛擬變數MS(...) 自動處理類別變數（性別、地區、等級）
模型評估train_test_split + MSE永遠需要！
