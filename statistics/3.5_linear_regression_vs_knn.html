兩種建模哲學的對決

在前幾節，我們深入學習了線性迴歸——它假設 f 具有特定的參數形式：\( f(X) = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p \)。這是一種參數方法（parametric method）。

現在，我們介紹一種完全不同的方法：K-近鄰法（K-Nearest Neighbors, KNN）——它不對 f 的形式做任何假設，屬於非參數方法（non-parametric method）。這兩種方法代表了統計學習中兩種對立的建模哲學。

🔑 核心問題：何時應該使用參數方法（如線性迴歸），何時應該使用非參數方法（如 KNN）？答案取決於數據的性質、變數數量、以及你的目標（預測 vs 解釋）。

參數方法 vs 非參數方法

特性參數方法（線性迴歸）非參數方法（KNN）
對 f 的假設假設特定形式（如線性）無假設，讓數據說話
參數數量固定（p+1 個 β）隨數據增長（隱含）
訓練方式一次性擬合參數記住全部數據（懶惰學習）
預測速度極快（只算點積）慢（需掃描全部訓練數據）
所需數據量較少較多
可解釋性高（每個 β 都有意義）低（黑箱）
靈活性低（受限於假設）高（理論上可擬合任何形狀）

KNN 如何運作？

給定一個預測點 \( x_0 \)，KNN 找出訓練集中距離 \( x_0 \) 最近的 K 個點，然後取這些點的 \( Y \) 值的平均作為預測值：

\[ \hat{f}(x_0) = \frac{1}{K} \sum_{i \in \mathcal{N}_0} y_i \]
其中 \(\mathcal{N}_0\) 是離 \(x_0\) 最近的 K 個訓練點的索引集合

距離通常使用歐氏距離（Euclidean distance）：

\[ d(x_0, x_i) = \sqrt{\sum_{j=1}^{p} (x_{0j} - x_{ij})^2} \]
💡 懶惰學習（Lazy Learning）：KNN 沒有真正的「訓練階段」——它只是記住整個訓練集。所有計算都在預測時進行。這與線性迴歸形成鮮明對比：線性迴歸在訓練時計算出 β 係數，預測時只需一次點積運算。

場景一：真實關係接近線性時

當 \( f(X) \) 的真實形式接近線性時，參數方法的優勢顯而易見：

  • 線性迴歸表現最佳——它的假設正好符合數據的真實結構，偏差和方差都低。
  • KNN（K=10）表現尚可，但測試誤差略高於線性迴歸——因為它沒有利用線性結構的先驗知識。
  • KNN（K=1）嚴重過擬合——每個預測只依賴一個鄰居，模型對訓練數據的雜訊極度敏感，測試誤差非常高。
⚠️ 關鍵教訓：當數據結構簡單時，簡單的模型通常勝出。沒必要為接近線性的數據使用高度靈活的模型——這樣只會增加方差，而不會減少偏差。

場景二：真實關係高度非線性時

當 \( f(X) \) 的真實形式明顯非線性時，情況完全逆轉：

  • 線性迴歸表現差——它強行用一條直線擬合彎曲的數據，導致高偏差（模型本身就不對）。
  • KNN（K=1~3）能很好地捕捉非線性模式，偏差很低，但如果數據有雜訊，方差會很大。
  • KNN（K=5~10）通常表現最佳——在偏差和方差之間取得良好平衡。
🔑 關鍵教訓：K 是 KNN 的關鍵超參數：
  • K 小 → 低偏差、高方差（過擬合風險）
  • K 大 → 高偏差、低方差（欠擬合風險）
  • 最佳 K 通常通過交叉驗證（cross-validation）來選擇

偏差-方差權衡：本章最重要的概念

線性迴歸 vs KNN 的比較，完美體現了統計學習中最核心的偏差-方差權衡（Bias-Variance Tradeoff）：

模型偏差（Bias）方差（Variance）適用場景
線性迴歸線性數據：低
非線性數據：高		始終低線性數據、高維數據、需解釋性
KNN（K 大）高（過度平滑）低高雜訊數據
KNN（K 小）低高（過擬合）低雜訊、低維度、大數據集
\[ \text{期望測試 MSE} = \text{Var}(\hat{f}(x_0)) + [\text{Bias}(\hat{f}(x_0))]^2 + \text{Var}(\epsilon) \]
測試 MSE 可以分解為方差、偏差平方、和不可約誤差三部分

線性迴歸的方差很低（因為只估計 p+1 個參數），但如果真實關係非線性，偏差可能很高。KNN 可以通過調小 K 來降低偏差，但代價是方差急劇增加。

維度災難（Curse of Dimensionality）

這是 KNN 最致命的弱點。當預測變數的數量 p 增加時：

  • 距離失去意義：在高維空間中，任意兩點之間的距離趨於均勻——所有點都變得差不多「遠」，「最近鄰居」的概念不復存在。
  • 數據密度暴跌：要保持相同的數據密度（每個單位體積內的訓練點數），所需的數據量必須隨 p 呈指數增長。例如，從 p=1 到 p=10，若原本 100 個點足夠，現在可能需要 \(100^{10}\) 個點。
  • 線性迴歸不受此影響：因為線性迴歸用參數來總結數據的結構，變數增加只會線性增加參數數量（p+1 個），而非指數級。
⚠️ 實務鐵律：當 p > 10 時，除非你擁有數百萬條數據，否則線性迴歸（或正則化版本如 Ridge/Lasso）幾乎總是優於 KNN。在現代機器學習中，這個教訓被反覆驗證。

Python 實作：比較線性迴歸與 KNN

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.neighbors import KNeighborsRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# 生成非線性數據
np.random.seed(42)
X = np.random.uniform(-3, 3, 200).reshape(-1, 1)
y = X.ravel()**3 - 3*X.ravel() + np.random.normal(0, 2, 200)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

# 線性迴歸
lr = LinearRegression().fit(X_train, y_train)
lr_mse = mean_squared_error(y_test, lr.predict(X_test))

# KNN 多種 K 值
for k in [1, 3, 5, 10, 20]:
    knn = KNeighborsRegressor(n_neighbors=k).fit(X_train, y_train)
    knn_mse = mean_squared_error(y_test, knn.predict(X_test))
    print(f"K={k:2d}  MSE={knn_mse:.3f}")

print(f"LR     MSE={lr_mse:.3f}")
# 預期：K=3~5 的 KNN 明顯優於線性迴歸（因為數據是三次方非線性）

實務決策框架

面對一個新的回歸問題，該如何選擇模型？以下是一個實用的決策流程：

  1. 始終從線性迴歸開始。它簡單、快速、可解釋。如果它的表現已經足夠好，就沒有必要複雜化。
  2. 檢查殘差圖。如果殘差顯示明顯的模式（例如 U 形曲線），說明線性假設不成立。
  3. 如果 p ≤ 4 且數據明顯非線性：嘗試 KNN，用交叉驗證選擇最佳 K。
  4. 如果 p > 10：堅持使用線性迴歸或正則化變體（第 6 章），KNN 在高維度下幾乎必輸。
  5. 用測試集公平比較。最終決定應基於測試誤差，而非主觀偏好。
📌 一句話總結：線性迴歸是「相信結構」的方法，KNN 是「相信鄰居」的方法。哪種信念更適合你的數據，取決於數據本身的性質。
